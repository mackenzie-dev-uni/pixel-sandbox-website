Amazon Pixel Test Page

Testing Instructions:

  1. Make sure you're accessing this page via http://localhost:8000/test-amazon-pixel.html
  2. Open Amazon Ad Tag Helper extension
  3. Uncomment the Amazon pixel code in the HEADER PIXEL AREA above
  4. Replace 'YOUR_PUB_ID_HERE' with your actual Amazon Publisher ID
  5. Save the file and refresh the page
  6. Check the extension - it should detect the pixel

Debug Checklist:

  • ✓ Page served over HTTP (not file://)
  • ✓ Pixel code is in <head> section
  • ✓ Pixel code is NOT commented out
  • ✓ Browser console has no errors (F12 → Console tab)
  • ✓ Network tab shows requests to amazon-adsystem.com

Common Issues:

  • Extension not detecting: Hard refresh (Ctrl+Shift+R or Cmd+Shift+R)
  • No network requests: Check browser console for JavaScript errors
  • Still not working: Try a different browser or disable other extensions
